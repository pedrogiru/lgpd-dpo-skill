# Código de conduta

Este projeto adota o [Contributor Covenant, versão 2.1](https://www.contributor-covenant.org/pt-br/version/2/1/code_of_conduct/).

Em resumo: trate todas as pessoas com respeito, discorde de ideias e não de pessoas, e lembre que
muita gente aqui contribui sem ser da área jurídica ou sem ser da área técnica.

Para relatar comportamento inadequado, use o
[relato privado do GitHub](https://github.com/pedrogiru/lgpd-dpo-skill/security/advisories/new) ou
contate o mantenedor pelo perfil [@pedrogiru](https://github.com/pedrogiru). Os relatos são tratados
com confidencialidade.
